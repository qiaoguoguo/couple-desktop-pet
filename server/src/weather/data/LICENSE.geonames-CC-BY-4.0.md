# GeoNames Attribution

This project contains a modified, reduced subset of the GeoNames geographical
database for China.

- Data source: [GeoNames](https://www.geonames.org/)
- Original country dump: [CN.zip](https://download.geonames.org/export/dump/CN.zip)
- License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)
- GeoNames dump documentation: [readme.txt](https://download.geonames.org/export/dump/readme.txt)

The source data was filtered, normalized, and combined with administrative-seat
coordinates as described in `README.md`. GeoNames does not endorse this project.
The data is provided without warranties of accuracy, timeliness, or completeness.
