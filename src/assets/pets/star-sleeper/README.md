# Star Sleeper Pet Assets

These PNG animation frames are first-party project-generated raster assets created with Codex built-in Image Gen from the user's provided character direction and reference image.

The reference image was used for style and character guidance only. The committed frames are not copied from open-source projects, downloaded third-party asset packs, web sprites, fonts, models, or audio.

The long animation frames were generated as 3 columns x 6 rows sprite sheets with a flat `#00ff00` background, split locally into per-frame images, processed with the Codex chroma-key removal script, and normalized to 512x512 transparent PNGs.

Current manifest actions:
- `idle-breathe`, `idle-look`, `idle-stretch`
- `walk`, `drag`, `sleep`
- `act-cute`, `act-typing`, `act-wave`, `act-hug`, `act-pout`, `act-drowsy`

Each action has 18 frames named `<action>-01.png` through `<action>-18.png`.
