# Star Sleeper Pet Assets

These PNG animation frames are project-generated raster assets created with Codex built-in Image Gen from the user's provided character direction and reference image.

The reference image was used for style and character guidance only. The committed frames are not copied from open-source projects or downloaded third-party asset packs.

Files in this directory are 512x512 transparent PNG frames for the built-in `star-sleeper` desktop pet manifest.
