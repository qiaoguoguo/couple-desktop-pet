# 静态边缘隐藏与事件通知设计

## 目标

将桌宠贴边后的体验收敛为安静、稳定的静态隐藏状态。边缘常驻形象不再播放动画或响应悬停，只在收到普通消息或小心意时显示一张可点击的通知卡。

本次不修改普通桌面状态下的消息、小心意、状态选择、配对和同步协议，也不重做现有窗口停靠、透明区域点击穿透和拖拽基础能力。

## 静态隐藏状态

- 桌宠拖到屏幕边缘并释放后，直接进入静态隐藏状态，不播放进入动画。
- 左、右、下边缘继续使用已批准的微型 Q-girl 睁眼透明资源，但只显示静态 `idle` 帧。
- 上边缘继续使用已批准的“双手吊在屏幕上沿”形象，但固定显示一张静态待机帧。
- 静态形象不眨眼、不位移、不缩放、不摇摆，不产生悬停反馈。
- 静态形象不显示在线圆点、离线圆点、活动状态或常驻徽标。
- 单击静态形象不执行唤回、菜单或其他动作。
- 按住静态形象拖动是唯一主动恢复方式：立即恢复完整桌宠并继续现有自定义拖拽。
- 从边缘拖出时不播放退出动画。

## 消息通知卡

- 桌宠处于静态隐藏状态且收到当前 active 普通消息时，显示现有边缘消息提示卡。
- 提示卡保留头像、消息预览和现有视觉风格，不改写远程消息内容或 FIFO 队列。
- 提示卡保持显示，直到用户点击打开或该消息因其他现有流程失效；不按时长收成未读徽标。
- 不支持悬停重展、悬停动画或提示卡自动收起。
- 点击提示卡后直接恢复完整桌宠并打开现有完整普通消息层。
- 用户确认或关闭消息后，桌宠保持普通完整状态，不自动回到边缘。

## 礼物通知卡

- 桌宠处于静态隐藏状态且收到当前 active 小心意时，显示现有边缘礼物提示卡。
- 提示卡保留现有插画、情绪文案和视觉风格，不提前展示暗号或物流信息。
- 提示卡保持显示，直到用户点击打开或该小心意因其他现有流程失效；不按时长收成心形徽标。
- 不支持悬停重展、悬停动画或提示卡自动收起。
- 点击提示卡后直接恢复完整桌宠并打开现有折叠小心意卡；揭示流程仍由现有完整卡片负责。
- 用户揭示、确认或关闭后，桌宠保持普通完整状态，不自动回到边缘。

## 对方状态

- 对方在线、离线和活动状态继续在应用状态中正常更新。
- 静态边缘隐藏状态不投影、显示或缓存状态提示卡及状态圆点。
- 桌宠恢复普通状态后，现有对方状态展示逻辑不变。

## 状态与模块边界

- `EdgeInteractionState` 只需要表达是否停靠以及停靠方向；生产流程不再使用 `enter`、`react`、`exit` 动画阶段。
- `EdgeNoticeState` 生产流程只消费 `message` 和 `surprise` 两类 active 通知；状态通知、收起徽标、悬停重展和计时器不再接入边缘 UI。
- 可以保留底层纯模块供历史测试或后续设计使用，但生产代码不得再触发已取消的边缘效果。
- `App` 继续协调从边缘通知进入完整消息层，但不再创建自动归位意图。
- `renderer` 只渲染静态边缘形象和当前消息/礼物通知卡。
- `desktop` 的原生停靠、工作区几何、精确交互区域和全局点击穿透语义保持不变。

## 输入区域

- 只有静态形象的 alpha 命中区域和当前通知卡注册为桌面交互区域。
- 透明舞台、已移除的状态点和不存在的徽标不能阻挡桌面点击。
- 静态形象必须支持按下后直接拖出，不能因取消单击行为而失去拖拽能力。
- 通知卡必须可点击，不能被透明窗口区域或拖拽手势拦截。

## 异常与回退

- 静态边缘资源加载失败时，取消边缘隐藏并恢复普通桌宠，不显示破图或文字占位。
- 原生停靠失败时，恢复安全可见位置并清除边缘状态。
- 点击通知卡恢复完整桌宠失败时，不确认、不丢弃当前消息，保留现有队列状态。
- 应用窗口被显式隐藏时不显示边缘通知；重新显示后当前未处理消息仍由现有队列提供。

## 验收标准

### 自动化

- 状态机测试证明贴边后直接进入静态状态，拖出后直接恢复，无 `enter`、`react`、`exit` 生产路径。
- 渲染测试证明静态形象固定使用睁眼/待机资源，不启动眨眼、悬停或阶段完成计时器。
- App 测试证明对方状态不会生成边缘提示，普通消息和小心意会显示对应通知卡。
- App 测试证明点击两类通知后打开对应完整内容，关闭后不自动归位。
- 交互区域测试证明只有静态形象和通知卡可命中，通知按钮可点击，透明区域继续穿透。
- 现有普通消息、小心意、拖拽、设置、点击穿透和同步测试继续通过。

### Windows 实机

- 左、右、上、下四边均只显示静态形象，没有在线圆点、悬停反馈、眨眼或动画。
- 收到普通消息时只显示消息提示卡，点击可打开完整消息。
- 收到小心意时只显示礼物提示卡，点击可打开完整礼物内容。
- 内容关闭后保持完整桌宠，不自动回边。
- 静态形象可按住拖回桌面，透明背景不遮挡桌面，拖动时没有矩形轮廓。
- 构建并运行 debug EXE，使用真实桌面截图核对最终效果。

## 非目标

- 不修改 Relay 协议、消息载荷、配对流程或服务器。
- 不新增边缘角色资源或重新设计通知卡视觉。
- 不删除普通桌面状态下的在线状态、消息和礼物展示。
- 不新增点击静态形象唤回、右键菜单、悬停预览、未读徽标或自动归位替代方案。
