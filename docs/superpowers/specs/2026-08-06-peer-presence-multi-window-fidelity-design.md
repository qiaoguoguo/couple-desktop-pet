# 多窗口陪伴状态高保真设计

## 背景

当前在线状态实现被限制在主桌宠 `320 x 360` 透明窗口内。虽然功能可用，但对方形象、状态文案和心动连线被压缩成小型控件，无法还原用户确认的情绪化渲染图。

本设计采用多个透明窗口组合成一个陪伴场景：主桌宠继续使用现有窗口，对方头像和状态、心动连线、离线留言小窝分别放在尺寸受控的卫星窗口中。卫星窗口跟随主桌宠移动，并在屏幕边缘自动镜像或隐藏。

唯一视觉基准是：

`docs/assets/references/peer-presence-emotional-target.png`

该图包含在线和离线两个概念状态。实现只还原桌宠、对方陪伴头像、状态胶囊、心动连线和离线留言小窝，不还原壁纸、任务栏、系统时间和右下角极小状态徽章。

本文所说的“与渲染图一致”，指上述浮动元素的角色比例、相对构图、状态层级、配色气氛和动画意图一致，不包含不同桌面分辨率下的壁纸、任务栏和绝对屏幕坐标逐像素复制。基准图尺寸为 `1672 x 941`，左半为在线态，右半为离线态。

## 目标

- 在线时直观看到对方形象、`TA 在线` 和 `正在陪你`，画面表达双方仍在同一桌面空间中。
- 离线时保留对方形象和温和等待状态，不让陪伴区域突然消失。
- 视觉比例、相对位置、色彩和层级接近目标渲染图，不再退化成普通状态条。
- 空白透明区域不能大面积阻断桌面点击。
- 状态窗口必须跟随桌宠移动，支持 Windows，并保持 macOS、Linux 的可实现边界。
- 新生成资源包提供适合陪伴头像窗口使用的专用素材。

## 非目标

- 不实现托盘或屏幕角落的极小状态徽章。
- 不实现壁纸、任务栏或系统时间模拟。
- 不实现离线消息持久化；离线留言小窝只提供情绪化等待视觉，不承诺消息离线送达。
- 不重做 Relay 配对、鉴权和在线状态协议。
- 不引入 PixiJS、Live2D、Spine 或骨骼动画。
- 不允许状态窗口远程控制对方电脑。

## 视觉规格

### 基准画布

- 主桌宠窗口继续保持 `320 x 360`。
- 默认场景从主窗口左边缘到右侧陪伴窗口右边缘约 `508px`，从陪伴窗口顶部到主窗口底部约 `408px`。
- 陪伴窗口默认显示在主桌宠右上方；右侧空间不足时整体镜像到左侧。
- 所有卫星窗口使用透明、无边框、置顶、跳过任务栏配置。

### 在线陪伴窗口

- 窗口尺寸：`168 x 176`。
- 默认位置：主窗口右边缘外 `20px`，主窗口顶部上方 `48px`。
- 头像圆窗：`94 x 94`，位于窗口水平中央。
- 头像在圆窗内占可视面积约 82%，显示头部和肩部，不显示缩小的全身形象。
- 圆窗使用弱边框、暖粉橙光晕和柔和外发光，不呈现系统头像按钮质感。
- 心形角标：`26 x 26`，位于圆窗右上，使用项目自有透明 PNG 资源。
- 主状态胶囊：`112 x 30`，圆角 `15px`，内容为状态点和 `TA 在线`。
- 次状态胶囊：`96 x 26`，圆角 `13px`，内容为 `正在陪你`。
- 两个胶囊间距 `6px`，使用半透明暖色玻璃质感，文字使用统一内置中文字体。

### 在线心动连线

- 连线使用独立的完全点击穿透窗口，基准尺寸 `196 x 112`。
- 起点视觉上落在主桌宠头部或心口附近，终点进入对方头像圆窗下方，不允许悬空断开。
- 连线为暖粉色细虚线，采用轻微弧线，不使用直角折线。
- 连线中段包含一个约 `24 x 24` 的发光心形资源。
- 动画心点沿连线从主桌宠移动到对方头像，连线窗口本身不接受任何鼠标事件。

### 离线陪伴窗口

- 位置和尺寸与在线陪伴窗口一致，避免状态切换时整体跳动。
- 优先使用资源包的 `portrait-offline.png`，显示睡眠、闭眼或安静等待的半身形象。
- 缺少离线头像时，使用 `portrait.png`，降低饱和度和亮度，并叠加月亮角标。
- 主状态胶囊内容为 `TA 离线`，次状态胶囊内容为 `等TA回来`。
- 色彩切换为低饱和蓝灰和柔和月光，不使用纯黑灰度。

### 离线留言小窝

- 使用独立点击穿透窗口，基准尺寸 `138 x 116`。
- 默认位置：主窗口右边缘外 `42px`，主窗口顶部下方 `204px`。
- 内容为项目自有的信封、小月灯和微光透明 PNG，不显示可点击按钮样式。
- 因当前没有离线消息持久化，该区域不接受点击，也不显示“留言已送达”等误导文案。
- 镜像到左侧时，留言小窝随陪伴窗口一起镜像布局。

### 字体与图形资源

- 状态文案使用授权明确的 `Noto Sans SC` 字体子集，授权文件随项目保留。
- 心形角标、流动心点、月亮角标和离线留言小窝使用项目自有透明 PNG。
- 不使用 emoji、文本符号、CSS 绘制爱心或手写 SVG 代替目标图形资源。

## 资源包扩展

### 文件结构

v3 资源包不提升 `formatVersion`，新增两个可选文件：

```text
my-pet.cdpet
|-- pet.json
|-- preview.png
|-- portrait.png
|-- portrait-offline.png
`-- motions/
```

规则：

- `portrait.png`：新生成器必须输出；现有资源包允许缺失。
- `portrait-offline.png`：新生成器应输出；现有资源包允许缺失。
- 导入器只允许这两个固定文件名，必须校验 PNG 签名和现有文件大小限制。
- 两张图建议为 `512 x 512` RGBA 透明 PNG。
- 角色头部和肩部应位于中央安全区，四周至少保留 8% 透明边距。
- 在线头像应保持角色正常神态；离线头像应是闭眼、睡眠或安静等待神态，不允许改变角色身份、服装和主要配色。
- 内置 `q-girl` 必须补齐两张头像；现有对外提供的女孩和男孩完整 v3 资源包也必须重新打包并包含两张头像。
- 初始 EXE 仍然只内置女孩完整资源，不因本功能额外内置男孩完整资源。

运行时解析顺序：

1. 在线：`portrait.png` -> `preview.png` -> 默认 motion 第一帧 -> `TA` 占位。
2. 离线：`portrait-offline.png` -> `portrait.png` 的离线滤镜 -> `preview.png` 的离线滤镜 -> `TA` 占位。

解析后的资源包增加：

```ts
interface ResolvedPetPackage {
  portraitUrl: string | null;
  offlinePortraitUrl: string | null;
}
```

## 多窗口架构

### 窗口组成

1. `main`：现有主桌宠窗口，负责桌宠动画、拖拽、菜单、消息气泡和设置。
2. `peer-presence`：对方头像和两行状态胶囊；在线时可点击打开消息输入框。
3. `peer-link`：心动连线和流动心点；始终完全点击穿透。
4. `offline-nest`：离线留言小窝；始终完全点击穿透，只在离线状态显示。

不把这些内容放入一个大透明窗口，因为 WebView 的透明像素不等于操作系统级点击穿透，大窗口会阻断桌面操作。

### 桌面窗口协调器

在 `desktop` 边界内新增 `CompanionWindowCoordinator`，统一负责：

- 创建、显示、隐藏和销毁卫星窗口。
- 跟随主窗口原生移动事件更新卫星窗口位置。
- 使用物理像素处理 DPI，避免跨缩放显示器漂移。
- 根据主窗口当前显示器的工作区选择右侧或左侧布局。
- 在工作区上下边缘执行位置钳制，保证所有可见内容不被裁切。
- 主窗口进入桌面边缘半隐藏时隐藏所有卫星窗口，恢复后重新出现。
- 应用退出时关闭所有卫星窗口，不留下后台窗口。

窗口坐标和可见性通过桌面桥接命令管理，React UI 不直接散落调用 Tauri 窗口 API。

### 状态同步

主窗口是运行时状态唯一来源。数据流为：

```text
Relay presence event
  -> useRealtimeSync
  -> main App builds CompanionSceneContentState
  -> desktop bridge sends content state to CompanionWindowCoordinator
  -> coordinator computes mirrored layout and broadcasts view state
  -> peer-presence / peer-link / offline-nest render
```

主窗口产生的内容状态至少包含：

```ts
interface CompanionSceneContentState {
  presence: "hidden" | "online" | "offline";
  portraitUrl: string | null;
  offlinePortraitUrl: string | null;
  sceneScale: number;
  suspended: boolean;
}
```

协调器计算并附加窗口布局状态：

```ts
interface CompanionSceneLayoutState {
  mirrored: boolean;
  compact: boolean;
}

type CompanionSceneViewState = CompanionSceneContentState &
  CompanionSceneLayoutState;
```

卫星窗口不得自行创建 WebSocket、读取配对信息或修改同步状态。

在线陪伴窗口点击后向主窗口发送 `open-message-composer` 事件。主窗口收到事件后沿用现有消息输入流程。离线状态不发送该事件。

## 动画导演层

动画由 `usePresenceMotionDirector` 或等价的独立状态机管理。它只消费 `CompanionSceneState`，不拥有网络或窗口定位逻辑。

### 状态

- `hidden`：未配对、连接状态未知、主窗口边缘半隐藏或应用主动隐藏。
- `entering-online`：上线出现动画。
- `online-idle`：在线持续陪伴循环。
- `online-hover`：鼠标进入可点击陪伴窗口。
- `online-press`：点击发送消息反馈。
- `transitioning-offline`：在线转离线。
- `offline-idle`：离线等待循环。
- `suspended`：收到远程消息、消息输入框打开、设置面板打开或主桌宠互动动画占用视觉焦点。

### 时间线

- 上线出现 `700ms`：连线从桌宠端显现，心点流向头像；头像从 `0.82` 缩放到 `1.04` 后回到 `1`；状态胶囊延迟 `180ms` 淡入并上移 `6px`。
- 在线循环 `5600ms`：头像上下移动不超过 `2px`，光晕透明度在 `0.72..1` 之间缓慢变化；流动心点每轮只经过一次，避免持续闪烁。
- 悬停反馈 `180ms`：头像放大到 `1.035`，胶囊上移 `2px`，不出现额外按钮或说明文字。
- 点击反馈 `320ms`：心形角标放大到 `1.18` 后回弹，流动心点加速向对方头像移动；消息输入框立即打开，不等待动画完成。
- 离线切换 `900ms`：在线光晕减弱、头像交叉淡变为离线头像、状态文字交叉淡变、留言小窝在最后 `360ms` 出现。
- 离线循环 `6000ms`：月光和小夜灯只做低幅度呼吸，头像不持续跳动。
- `prefers-reduced-motion: reduce`：取消位移、缩放和流动心点，只保留不超过 `180ms` 的淡入淡出。

动画只使用 transform、opacity 和低成本阴影变化，不使用大面积实时模糊滤镜。

## 场景互斥规则

- 收到远程消息并切换主桌宠 message motion 时，卫星窗口进入 `suspended` 并淡出；消息确认结束后恢复当前在线或离线状态。
- 消息输入框打开时卫星窗口淡出，关闭后恢复。
- 设置面板打开时卫星窗口隐藏，避免多个窗口争抢焦点。
- 主桌宠进入边缘半隐藏时卫星窗口立即隐藏；恢复主桌宠后重新播放简短出现动画。
- 主桌宠拖拽时卫星窗口跟随，不播放上线动画；拖拽结束后只校正布局方向。
- 本地 Relay 断开导致对方状态未知时隐藏卫星窗口，不错误显示为对方离线。

## 边缘、多屏和跨平台行为

- 默认优先放在主桌宠右侧。
- 当前显示器右侧剩余空间不足 `214px` 时镜像到左侧。
- 左右都不足时隐藏心动连线和留言小窝，将陪伴窗口钳制在工作区内；不允许窗口跨出屏幕。
- 多屏切换以主窗口中心点所在显示器为准，并在移动结束后重新选择布局方向。
- 坐标计算使用物理像素，UI 内部尺寸通过 `sceneScale` 映射。
- Windows 作为首要验收平台；macOS 和 Linux 至少完成构建、窗口创建、移动和隐藏逻辑验证。
- 如果某平台不能稳定实现非激活可点击卫星窗口，该平台允许点击陪伴窗口时短暂获得焦点，但不得显示任务栏图标或窗口边框。

## 错误和降级

- `portrait.png` 加载失败时立即回退 `preview.png`，不显示破图图标。
- 所有头像来源失败时显示与目标配色一致的 `TA` 占位圆窗。
- 卫星窗口创建失败时记录错误并隐藏整组状态，不影响主桌宠、设置和退出功能。
- 单个装饰窗口失败时隐藏该装饰，不能阻塞 `peer-presence` 点击或主桌宠拖拽。
- 跨窗口事件解析必须校验字段，未知字段忽略，非法状态不渲染。
- 退出或取消绑定时清空卫星窗口状态和图片 URL。

## 测试与验收

### 自动测试

- Rust 或桌面桥接测试覆盖右侧布局、左侧镜像、上下边缘钳制、多屏工作区和 DPI 坐标。
- 资源包导入测试覆盖两个新增 PNG、缺失回退、非法签名、超限文件和允许文件白名单。
- React 组件测试覆盖在线、离线、缺图、悬停、点击、减少动态效果和 suspended 状态。
- App 集成测试覆盖在线点击打开消息输入框、离线不可点击、收到消息时暂停陪伴场景和边缘半隐藏时隐藏。
- 窗口生命周期测试覆盖启动、取消绑定、隐藏、恢复和退出清理。

### 视觉基准

- 建立固定状态的视觉测试入口，分别渲染 online、offline、hover、press、suspended 和 reduced-motion；基准截图由目标图测量值生成，提交后不得在同一功能改动中无审核更新。
- 使用目标图中的在线和离线区域作为构图基准，检查头像圆窗、状态胶囊、主桌宠和连线的相对比例。
- 默认比例下，头像圆窗直径应约为主桌宠可见高度的 `0.38..0.42`。
- 主桌宠与头像圆窗之间的水平可见间距应约为主桌宠可见高度的 `0.22..0.30`。
- 主要元素位置与仓库固定视觉基准截图误差不超过 `2px`；阴影和字体抗锯齿不做逐像素硬判定。
- 视觉测试必须使用真实 `portrait.png`，不能用文本占位或全身 `preview.png` 代替。

### 真实桌面验收

- 在 Windows 启动最新 debug EXE，实际截取在线、离线、拖拽、右边缘镜像、消息输入和边缘半隐藏状态。
- 检查透明空白区域是否阻断桌面图标、窗口和任务栏操作。
- 检查任务栏只存在预期行为，卫星窗口不产生额外图标。
- 将真实在线和离线截图与 `peer-presence-emotional-target.png` 并排检查；未完成该步骤不得交付。

## 实施边界

本功能由以下独立边界组成：

- `desktop`：卫星窗口生命周期、位置、点击穿透和多屏协调。
- `assets`：portrait 资源合同、导入验证和 URL 解析。
- `sync`：纯状态场景组件和动画导演层，不修改 Relay 协议。
- `app`：把现有同步状态映射为场景状态，处理打开消息输入框事件。
- `ui assets`：项目自有心形、月亮和离线留言小窝透明 PNG，以及字体授权文件。

实现不得把窗口 API、资源包解析、WebSocket 和动画时间线重新堆进 `App.tsx`。
